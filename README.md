# LGST 1010 Midterm Practice

203 practice questions across ten exams, lecture banks, readings, and Studocu, plus six interactive decision trees.

Open `index.html` in a browser, or serve this folder with any static web server. No build step or installation is required.

Main midterm scope: readings 001–015. Generated prompts, proposed answers, source ambiguities, and extra tree branches are labeled. Written responses reveal an example and guidance for AI grading after submission.

The business tree is rebuilt from uploaded reading 013 with source-linked federal-tax and Pennsylvania-law clarifications and LLP as a modest extension. All provided source files are included under `sources/`.
